F 请求怎么走

App只带邀请码和设备标识，不带任何 Key
中转（作者服务器）查码是否有效 → 查该码额度和当月总额 → 限速 → 换上真正的 Key 转发 → 按实际 token 记账
模型只允许润色用的那一个模型，限制单次长度
不保存中转只记：哪个码、时间、token 数、花费。不记正文
