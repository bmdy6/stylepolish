# StylePolish 使用说明

[项目仓库](https://github.com/bmdy6/stylepolish) · [下载最新版本](https://github.com/bmdy6/stylepolish/releases/latest)

需要 macOS 13+。从菜单栏进入设置，填写 OpenAI 兼容接口、Key 和模型，授权辅助功能，再启用要使用的 App。

## 构建与签名

`swift test` 运行默认离线测试；`scripts/build-app.sh` 构建 release bundle。
脚本仅使用专用签名钥匙串中已有的有效身份，找不到时自动 ad-hoc 签名，不要求作者的证书。
首次构建不会创建钥匙串。可选运行 `scripts/setup-signing.sh`：创建空密码的专用 `~/Library/Keychains/stylepolish-signing.keychain-db`，生成本机自签名证书 `StylePolish Local`，授予 codesign 非交互使用权限；不会使用登录钥匙串。
已有专用钥匙串时构建会调用该脚本自动解锁并配置权限；旧的机器生成密码文件会迁移后删除。
`STYLEPOLISH_ADHOC=1 scripts/build-app.sh` 可明确跳过钥匙串。ad-hoc 更新可能需要重新授权辅助功能；自签名也不等于 Developer ID 或 Apple 公证。

## 详细设置与快捷键

Key 按 ai-vault → 本地文件 → 未配置的顺序选择。设置显示来源与末 4 位；未配置时提示「填一次 Key 即可」并提供 [OpenAI Key 获取链接](https://platform.openai.com/api-keys)。启动时读取一次，后续请求使用内存；修改外部文件或 vault Key 名称后点「重新读取」。JSON 损坏、找不到 Key 时会提示并尝试本地文件；权限不是 600 时提醒但仍可使用。App 不需要钥匙串，不会因 Key 读写弹出密码框。旧的钥匙串条目可以手动删除。

在系统设置 → 隐私与安全性 → 辅助功能中允许 StylePolish，然后回到设置点“授权 / 刷新”。若键盘监听仍不可用，检查“输入监控”并重启 App。预览按键需要系统事件监听权限。

默认启用微信、飞书、Claude、Linear 桌面版的 bundle id。设置支持选择 App 或手动增删 bundle id。**浏览器中的 Linear 必须添加实际浏览器**：白名单按 App 而非网站生效，因此浏览器的所有普通文本框都会启用。密码输入框与非文字角色拒绝读取。

v2 默认自动检查：停笔 1.5 秒后只请求变化的句子（设置中可用滑块调为 0.5–3 秒）；不足 4 字、密码框和无法经 AX 读写的输入框不自动检查。检测到建议后，在输入框下方自动显示红删绿增的整句预览条；取不到位置时显示在鼠标附近。预览不抢焦点，继续打字会作废旧预览，下一次检查再更新。`⌥Enter` 一次全部采纳，`Esc` 忽略这次预览。红色波浪线表示错字/赘词，黄色表示通顺/书面表达；点击下划线或停留 300ms 打开卡片，逐条采纳、忽略或关闭类别。取不到文字位置时保留角标和建议列表。

严格程度默认“标准”（错字、赘词、通顺：语序、搭配、成分残缺、指代不清、句子太绕）；宽松只提示错字，严格额外允许更书面的表达。无上下文不能确定的指代保留原文，不猜事实。禁用类别只影响当前档位，可在设置恢复。通知不完整的 App 会用 500ms 轮询补足；模型请求耗时另计。

v1 `⌥ Space` 备用入口默认关闭，在设置打开后才注册快捷键：

1. 聚焦输入框，按 `⌥ Space`。有选区则只润色选区，没有则润色整个输入框。
2. 预览：`Enter` 写回、`E` 修改、`O` 切换原文、`Esc` 取消。无改动时显示“不用改”，`Enter` 关闭。
3. 修改：可输入多行，`⌘Enter` 写回，`Esc` 返回预览。浮窗宽 440，最高 320，长内容滚动。
4. 错误：显示原因，`R` 重试，`Esc` 关闭。原输入不变。
5. 输入框的 App、元素、文字或选区变化时拒绝写回，改为复制并提示“输入框已变化，已复制”。**不会自动切回其他 App，也不会模拟 Return。**

对于 AX 读不到正文的普通文本框，先提示“这个输入框读不到，请先选中文字再按快捷键”。在同一输入框手动选中后再次按快捷键，才走 `⌘C`/`⌘V` 的兼容路径；复制前保存剪贴板，读取/粘贴后恢复所有可读取的数据类型。粘贴等待 300ms 供目标 App 读取剪贴板；此路径仍需逐 App 验收。期间若用户复制了新内容，不覆盖那份新剪贴板。

个人词表可放在 `~/.style-polish/lexicon.json`，不存在时跳过。可参考 [模板](../lexicon.example.json) 设置术语、别名和适用语境；文件只在本地维护，请勿提交个人词表。

口吻档案可选，支持 `~` 路径；不存在则忽略。档案只在发起润色请求时加入系统提示词。仓库不包含个人档案。

## 隐私与记录

- 原文和可选口吻档案会发给**你自己配置的模型服务**，请根据该服务的隐私政策决定哪些文字适合使用。没有额外分析、遥测或历史上传。
- API Key 保存在本机 ai-vault 或专用 Key 文件中，请妥善保护这些明文文件；运行时使用内存和 Authorization Header，不写入 UserDefaults、历史或日志。拒绝 HTTP 外网端点和 HTTP 重定向，本机 HTTP 用于开发兼容服务。
- 接受、修改后写回、取消均追加 `~/Library/Application Support/StylePolish/history.jsonl`，权限 `0600`。字段只有 `ts, app_bundle_id, input, output, final, action, model, latency_ms`；取消 `final` 为 null。目标变化而仅复制时按取消记录，`final` 为 null。
- 记录包含原文与改写内容，请妥善保护本机账号。设置可打开记录目录、确认后清空记录。v1 只记录，不学习。
- v2 会按句子发送文字；字符差异使用 UTF-16 定位。新增事件字段为 `ts, app_bundle_id, sentence, original, replacement, kind, action, level, model`；action 为 `accept/ignore/expired/hidden`。未显示类别也记录 hidden，原文改变导致建议失效记录 expired。与 v1 事件共存，权限保持 0600；没有自动调档、规则学习或上传历史。
- 模型请求使用临时 URLSession、SSE、30 秒总截止时间。取消会取消在途请求，网络失败不执行写回。


## 诊断

菜单「探测当前输入框」仅记录角色、长度、范围和位置，不含正文，保存到 `~/Library/Logs/StylePolish/probe-<时间>.json`。
`diagnostics.jsonl` 位于同目录，记录阶段、耗时与错误分类，不含正文或 Key。历史记录另含原文和改写，请保护本机账号。
模型失败时原文保持不变；接口不接受速度参数时选择「兼容（不指定速度）」。
权限或更新异常时检查辅助功能授权，键盘监听不可用时再检查输入监控。
默认不运行界面、剪贴板或付费 live 测试；这些需要显式 opt-in，不能用离线测试代替真实 App 验收。
