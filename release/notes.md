# StylePolish 0.5.0

- 越用越懂你：同一个错字采纳 2 次后，本地直接标出；单个字的错字（如 在/再）交给模型结合语境判断。
- 同一条建议忽略 2 次后不再提示，可在设置「我的习惯」里恢复；某类建议很少采纳时只提醒模型，不自动关闭。
- 菜单栏新增「本周表达报告」：采纳率、错字比上周、最常犯的 3 个、下周留意。
- 写回没确认成功时不再记为采纳（#17）。
- 全部只读本机记录，不上传、不调用模型学习；设置里可整体关闭。

本次只经过离线单测、release 构建和离屏渲染；未在微信里做真机采纳验收。

# StylePolish 0.4.0

- 无 Key 也能用：151 条本地错写词表，加白名单重复字词、标点和个人词表别名检查。
- AI 失败时当次回退本地规则，菜单写清 Key、额度、网络或授权原因。
- 首次启动走「授权 → 润色方式 → 试一句」，已授权自动跳过第一步。
- 设置按用途分四组，接口参数等进入默认折叠的高级设置。

安装：解压后先把 App 拖进「应用程序」再打开，不要在下载文件夹里直接双击。首次右键 → 打开（没有 Apple 公证），macOS 13+。
升级后签名变化可能使旧辅助功能授权失效；从菜单「需要授权」重开引导，旧开关无效时移除旧条目再添加应用程序中的 App。

本次只经过离线单测、release 构建和离屏渲染；未安装、未运行各聊天 App 的真实采纳写回验收，也未调用真实模型。

# StylePolish 0.3.2
- 整段润色不再给英文两边加空格、不把小写英文改成大写
- 建议列表可以滚动，不会一滚就关
- Esc 关掉预览后，重新打开列表仍可「全部采纳」
- ⌥Enter 只在当前输入框有建议时生效，不再全局占用
- 逐条采纳在不接受直接写入的输入框里改走粘贴
- 只有确认写回成功才记为采纳；没确认时保留建议并提示

安装：解压后拖进「应用程序」，第一次右键 → 打开（没有 Apple 公证）。仅 Apple Silicon，macOS 13+。
写回相关改动只经过单元测试，尚未在各聊天 App 逐一实测。
